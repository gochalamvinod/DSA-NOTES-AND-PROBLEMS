# TWO POINTERS — 75 PRACTICE QUESTIONS

## 1. Opposite Direction / Converging Pointers

### Easy

1. Valid Palindrome  
   Given a string, determine whether it is a palindrome after ignoring non-alphanumeric characters and case.

2. Two Sum II — Input Array Is Sorted  
   Given a sorted array and a target, find two numbers whose sum equals the target.

3. Reverse String  
   Reverse a character array in-place.

4. Squares of a Sorted Array  
   Return the squares of a sorted integer array in non-decreasing order.

5. Merge Two Sorted Arrays  
   Merge two sorted arrays into one sorted array.

### Medium

6. Container With Most Water  
   Find two lines that form a container holding the maximum amount of water.

7. 3Sum  
   Find all unique triplets in an array whose sum is zero.

8. Remove Duplicates From Sorted Array II  
   Remove duplicates in-place so each value appears at most twice.

9. Boats to Save People  
   Each boat can carry at most two people. Find the minimum number of boats needed.

10. Sort Colors  
    Sort an array containing only 0, 1, and 2 in-place.

### Hard

11. Trapping Rain Water  
    Given elevation heights, calculate how much rain water can be trapped.

12. 4Sum  
    Find all unique quadruplets whose sum equals a target.

13. 3Sum Closest  
    Find three integers whose sum is closest to a given target.

14. Valid Triangle Number  
    Count the number of triplets that can form a valid triangle.

15. 4Sum With Sorted Pair Sums  
    Given four arrays, count quadruplets whose total sum is zero using sorted pair sums and two pointers.

## 2. Same Direction / Fast & Slow

### Easy

16. Remove Duplicates From Sorted Array  
    Remove duplicates in-place and return the number of unique elements.

17. Remove Element  
    Remove all occurrences of a given value in-place.

18. Move Zeroes  
    Move all zeroes to the end while maintaining the relative order of non-zero elements.

19. Move Negative Numbers to the Front  
    Rearrange an array so negative values appear before non-negative values.

20. Compact Positive Values  
    Move all positive values to the beginning of the array and return the resulting length.

### Medium

21. Remove Duplicates From Sorted Array II  
    Keep at most two occurrences of each value in-place.

22. Sort Array by Parity  
    Rearrange the array so even numbers come before odd numbers.

23. String Compression  
    Compress consecutive repeated characters in-place.

24. Remove All Adjacent Duplicates in String  
    Repeatedly remove adjacent equal characters until no such pair remains.

25. Duplicate Zeros  
    Duplicate every occurrence of zero in-place while keeping the original array length.

### Hard

26. Minimum Number of Removals to Make Mountain Array  
    Remove the minimum number of elements so the remaining array is strictly increasing and then strictly decreasing.

27. Shortest Unsorted Continuous Subarray  
    Find the shortest continuous subarray which, if sorted, makes the entire array sorted.

28. Stable Partition Around a Pivot  
    Rearrange an array into values less than pivot, equal to pivot, and greater than pivot while preserving relative order.

29. Three-Way Partition  
    Partition an array into values below a lower bound, values inside a range, and values above an upper bound.

30. Remove Duplicates From Sorted Linked List II  
    Remove every value that occurs more than once from a sorted linked list.

## 3. Sliding Window — Variable Size

### Easy

31. Maximum Sum Subarray of Size at Most K  
    Find the maximum sum of a non-empty contiguous subarray whose length is at most K. Assume all numbers are positive.

32. Longest Subarray With Sum at Most K  
    Find the longest contiguous subarray whose sum is at most K. Assume all numbers are positive.

33. Longest Substring With At Most Two Distinct Characters  
    Find the length of the longest substring containing at most two distinct characters.

34. Longest Ones After Removing At Most One Zero  
    Find the longest sequence of 1s that can be obtained after removing at most one zero.

35. Minimum Size Subarray Sum  
    Find the minimum length of a contiguous subarray whose sum is at least target. Assume all numbers are positive.

### Medium

36. Longest Substring Without Repeating Characters  
    Find the length of the longest substring without repeated characters.

37. Longest Repeating Character Replacement  
    Find the longest substring that can be made of one repeated character after replacing at most K characters.

38. Fruit Into Baskets  
    Find the longest contiguous subarray containing at most two distinct values.

39. Longest Subarray of 1s After Deleting One Element  
    Find the longest subarray containing only 1s after deleting exactly one element.

40. Longest Substring With At Most K Distinct Characters  
    Find the length of the longest substring containing at most K distinct characters.

### Hard

41. Minimum Window Substring  
    Find the smallest substring of S containing all characters of T with the required frequencies.

42. Subarrays With K Different Integers  
    Count the number of subarrays containing exactly K distinct integers.

43. Longest Continuous Subarray With Absolute Diff Less Than or Equal to Limit  
    Find the longest subarray where the difference between its maximum and minimum values is at most limit.

44. Minimum Number of K Consecutive Bit Flips  
    Find the minimum number of length-K flips needed to turn a binary array into all 1s.

45. Count Subarrays With Score Less Than K  
    For positive numbers, count subarrays whose score, defined as sum multiplied by length, is less than K.

## 4. Sliding Window — Fixed Size

### Easy

46. Maximum Sum of K Consecutive Elements  
    Find the maximum sum among all contiguous subarrays of exactly K elements.

47. Minimum Sum of K Consecutive Elements  
    Find the minimum sum among all contiguous subarrays of exactly K elements.

48. Average of Every K Elements  
    Return the average of every contiguous window containing exactly K elements.

49. First Negative Number in Every K-Size Window  
    For every window of size K, return its first negative number.

50. Count Windows With Sum Greater Than X  
    Count how many windows of exactly K elements have a sum greater than X.

### Medium

51. Maximum Number of Vowels in a Substring of Length K  
    Find the maximum number of vowels in any substring of length K.

52. Maximum Average Subarray I  
    Find the contiguous subarray of length K having the maximum average.

53. Defuse the Bomb  
    Replace each element with the sum of the next or previous K elements depending on the sign of K.

54. Grumpy Bookstore Owner  
    Maximize the number of satisfied customers by using a secret technique for one continuous window of exactly K minutes.

55. Find All Anagrams in a String  
    Find all starting indices of substrings of S that are anagrams of P.

### Hard

56. Sliding Window Maximum  
    Return the maximum value in every window of size K.

57. Sliding Window Minimum  
    Return the minimum value in every window of size K.

58. Maximum Frequency After At Most K Increments  
    Find the maximum frequency of an element after at most K increment operations.

59. Maximum Sum of Two Non-Overlapping Subarrays  
    Find two non-overlapping subarrays with specified lengths having the maximum combined sum.

60. Count Complete Subarrays  
    Count the number of subarrays containing every distinct value that appears in the entire array.

## 5. Fast & Slow — Different Speeds

### Easy

61. Middle of the Linked List  
    Find the middle node of a singly linked list.

62. Linked List Cycle  
    Determine whether a linked list contains a cycle.

63. Find the Middle Value of an Array  
    Use two pointers moving at different speeds to locate the middle position.

64. Happy Number  
    Determine whether repeatedly replacing a number with the sum of the squares of its digits eventually reaches 1.

65. Remove Nth Node From End of List  
    Remove the Nth node from the end of a singly linked list using two pointers.

### Medium

66. Linked List Cycle II  
    Return the node where a cycle in a linked list begins.

67. Happy Number Without Extra Memory  
    Detect whether a number is happy using Floyd's cycle detection without a HashSet.

68. Palindrome Linked List  
    Determine whether a linked list is a palindrome using O(1) extra space.

69. Reorder List  
    Reorder a linked list as L0 → Ln → L1 → Ln-1 → ...

70. Split Linked List Into Two Halves  
    Split a linked list into two halves using slow and fast pointers.

### Hard

71. Find the Duplicate Number  
    An array contains n + 1 integers where every integer is in [1, n]. Find the duplicate using O(1) extra space.

72. Find Linked List Cycle Entry  
    Detect a cycle and return its entry node using Floyd's algorithm.

73. Intersection of Two Linked Lists  
    Find the node at which two singly linked lists intersect using O(1) extra space.

74. Circular Array Loop  
    Determine whether a circular array contains a valid cycle with consistent movement direction.

75. Find Duplicate Without Modifying the Array  
    Find the duplicate number without modifying the input array and using O(1) extra space.
